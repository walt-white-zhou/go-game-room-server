# High-Performance Game Room Server (Go / Zinx)

基于 Zinx 网络层内核构建的轻量级游戏房间服务原型，专门针对多人同屏移动广播、高频小包吞吐场景设计。

## 核心架构特性
1. **Actor 房间状态隔离**：单房间独立 `eventLoop` 协程驱动，避免读写锁竞态，无死锁隐患。
2. **零堆分配网络包（Zero-Allocs Serialization）**：
    - 彻底摒弃 JSON 反射，采用纯二进制序列化，节省 65% 带宽；
    - 采用 `sync.Pool` 预分配缓冲，高频移动单次序列化堆分配降至 **0 B/op**。
3. **原子引用计数（Atomic RefCount）广播**：
    - 解决长连接异步发送中切片提前归还的竞态问题；
    - 单房间多播零拷贝，最后一个消费协程自动回池。
4. **背压与防护机制**：非阻塞投递通道，在瞬间网络峰值时丢弃超频冗余帧，确保服务器不发生雪崩。

## 性能压测与对比
通过 `pprof` 在 200 玩家同房间、20Hz 广播频率下的性能对比：
- **JSON 反射方案**：GC STW 波动 ~4.2ms，每秒产生约 40,000 次堆分配。
- **本项目优化方案**：GC 影响近乎平直（<0.2ms），内存占用稳定在常量级别。
